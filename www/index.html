私有 Docker Registry 拉取缓存

Docker 镜像加速站

把国内拉不到的 Docker Hub / GHCR / GCR / Quay / k8s / NVIDIA / MCR 请求，缓存到这台能访问上游的服务器上。

1. Docker Hub（改 daemon.json，镜像名不用改）

{
  "registry-mirrors": ["https://YOUR_DOMAIN"]
}

只有 IP、走 HTTP 时：

{
  "registry-mirrors": ["http://YOUR_IP"],
  "insecure-registries": [
    "YOUR_IP",
    "YOUR_IP:80",
    "YOUR_IP:5001",
    "YOUR_IP:5002",
    "YOUR_IP:5003",
    "YOUR_IP:5004",
    "YOUR_IP:5005",
    "YOUR_IP:5006"
  ]
}

一键配置：

curl -fsSL http://YOUR_IP/install.sh | sudo MIRROR=http://YOUR_IP sh
sudo systemctl restart docker
docker pull nginx:alpine

2. 其他仓库（改镜像名前缀）

原地址HTTPS 子域名HTTP 端口
ghcr.io/xxxghcr.YOUR_DOMAIN/xxxYOUR_IP:5001/xxx
gcr.io/xxxgcr.YOUR_DOMAIN/xxxYOUR_IP:5002/xxx
quay.io/xxxquay.YOUR_DOMAIN/xxxYOUR_IP:5003/xxx
registry.k8s.io/xxxk8s.YOUR_DOMAIN/xxxYOUR_IP:5004/xxx
nvcr.io/xxxnvcr.YOUR_DOMAIN/xxxYOUR_IP:5005/xxx
mcr.microsoft.com/xxxmcr.YOUR_DOMAIN/xxxYOUR_IP:5006/xxx
 
# 原命令
docker pull ghcr.io/actions/runner:latest
# HTTPS
docker pull ghcr.YOUR_DOMAIN/actions/runner:latest
# HTTP
docker pull YOUR_IP:5001/actions/runner:latest

3. Kubernetes / containerd

version = 2

[plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
  endpoint = ["https://YOUR_DOMAIN"]

[plugins."io.containerd.grpc.v1.cri".registry.mirrors."ghcr.io"]
  endpoint = ["https://ghcr.YOUR_DOMAIN"]

[plugins."io.containerd.grpc.v1.cri".registry.mirrors."registry.k8s.io"]
  endpoint = ["https://k8s.YOUR_DOMAIN"]

注意

加速站所在机器必须能访问官方仓库，或通过 HTTP_PROXY 出网。国内同机房互拷缓存才有意义。

建议填写 Docker Hub 账号，避免匿名拉取被限流。私有镜像、登录鉴权仓库请继续走原地址。
